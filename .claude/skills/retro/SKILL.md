산출물은 성찰 산문이 아니라 레포/메모리에 실제로 남는 변경이다 — CLAUDE.md 규칙 한 줄, ADR, `docs/retros/`, memory, 스킬 변경. 순이익은 여러 작업에 걸친 반복 패턴과 프로세스 결함을 잡는 데 있다(단건 결정의 why는 ADR, 단건 사실은 memory가 이미 잡는다). 학습이 없으면 `회고 skip(학습 없음)` 한 줄로 끝낸다 — 억지로 짜내지 않는다. 인자(선택): 대상 작업 한 줄 요지(예: `/retro ADR-0006 감사 sink`); 없으면 직전 완료 작업.

## 0. 돌릴까

돌린다: 다단계 작업에서 리뷰·테스트·사용자 정정·놀람이 뭔가 잡은 경우. 건너뛴다: typo·설정·한 줄 → `회고 skip(trivial)` 한 줄. 매번 도는 회고는 그 자체가 의례다.

## 1. 증거 — 잘된 얘기가 아니라 마찰

- 처음 틀렸던 지점: 외부 리뷰·테스트가 잡았는데 self-review는 놓친 것, 걸린 라운드 수.
- 사용자 정정: 방향 전환·놓친 것 지적 — 가장 강한 재사용 신호.
- 헛돈 지점: 막다른 길, 반복한 수정, 잘못한 가정, 놓친 도구·채널·명령.
- 놀란 점: API·도구·환경이 예상과 다르게 군 곳.

위임 작업(dispatch-issue)은 워커 transcript를 못 본다. 증거는 dispatch-issue §5a가 persist한 PR 코멘트(`## 회고 증거 (retro evidence)` — 마찰·판단·리뷰 대응; 조회는 `gh api "repos/$SLUG/issues/P/comments"`, cloud는 `mcp__github__pull_request_read`도 가능)와 워커 반환의 마찰 줄뿐이다. 보이지 않는 것을 추측하지 말고 회고를 오케스트레이션 수준 + 반환된 마찰로 명시적으로 한정한다(dispatch-issue §7이 이 절을 인용).

## 2. 2축 평가

① 결과물 품질 — 리뷰·테스트가 잡은 것이 self-review로 잡혔어야 했나. ② 프로세스 — 어디서 헛돌았나, 놓친 채널·잘못한 가정·반복 정정.

외부 평가자를 부를 땐 대상을 구분한다. 이미 외부 리뷰를 거친 결과물은 재리뷰하지 않는다 — 의례이며, 리뷰 기록을 §1 증거로 읽으면 된다. 고-stakes이거나 결과물이 크게 흔들렸으면 회고 결론(학습의 프레이밍·라우팅이 과/소하지 않은지)을 독립 검토자에게 검증받는다 — local은 사용자 전역 리뷰 스킬(codex 리뷰 등)이 있을 때, cloud는 읽기 전용 서브에이전트(`claude-advisory`; advisory (same-model) — ADR-0008 독립 검증자가 아니다). 어느 쪽이든 CLAUDE.md "모델/런타임 프로파일" 표를 따른다. self-grade는 후하다.

## 3. 재발 점검

이 학습이 처음인가 또인가. `docs/retros/*.md`, CLAUDE.md 규칙, ADR Consequences, `go-tdd-implementer` 운영 불변식을 먼저 보고, 세션이 memory 디렉터리를 제공할 때만 `grep -ril "<키워드>" "<memory-dir>"`. 처음 → §4로 라우팅. 재발 → 승격 신호(§4 승격 바). 재발이 쌓였으면 memory 통합을 한 절로 제안한다.

## 4. 라우팅 (학습 1개 = 표면 1개) — 캡처는 실행 가능해야 한다

캡처는 명령·규칙·체크여야 한다 — 훈계는 증발한다. 품질 게이트: 명령/규칙/체크가 아니면 다시 쓴다. Bad(훈계): "리뷰 코멘트를 꼼꼼히 확인하기". Good(실행 가능): "PR 후 CLI 출력뿐 아니라 봇 코멘트도 확인: `gh api "repos/$SLUG/pulls/P/comments" --jq '.[] | {path,line,body}'`"(양 환경). 실례는 retro "실행 가능한 개선".

| 학습 종류 | 표면 |
|---|---|
| 항상 켜둘 규칙 | CLAUDE.md — 아래 승격 바 통과 시만 |
| 결정의 why·버린 대안 | ADR(`docs/adr/`) 또는 `/architect` |
| 다PR 캠페인 서사·사고 목록 | `docs/retros/` |
| 세션 간 feedback·비자명 사실 | memory(세션이 제공할 때; 없으면 `docs/retros/` 또는 PR 코멘트) |
| 반복되는 프로세스 자체 | 스킬·에이전트 변경(CLAUDE.md "게이트 승격 규칙" 적용) |

CLAUDE.md 승격 바: 매 세션 로드되는 가장 비싼 자리다. 실제로 재발했거나(§3) 한 번이라도 고비용 실패를 낸 학습만 규칙으로 올린다. 대부분의 학습은 memory·`docs/retros/`에 머문다.

## 5. 사람 게이트 (쓰기 무게에 비례)

- memory 쓰기: 자율 진행 — 메모리 시스템이 원래 그렇게 동작한다. 프리뷰 불필요.
- CLAUDE.md·ADR·스킬/에이전트·`docs/retros/` 쓰기: 쓰기 *전* 프리뷰하고 승인받는다 — 규칙·결정·에이전트 동작을 바꾸고 레포에 영속되므로 무게가 다르다(§4가 "프로세스 → 스킬·에이전트 변경"으로 라우팅한 경우 포함).
